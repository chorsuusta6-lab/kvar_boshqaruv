# 🏠 KV Boshqaruv

Kvartira ijaraga berish boshqaruv tizimi (PWA).

## Xususiyatlar
- 🏢 KV (kvartiralar) boshqaruvi
- 👥 Ijarachilar va to'lovlar
- 💸 Xarajatlar
- 📊 Hisobotlar (.xls yuklash)
- 👮 Navbatchilik tizimi
- 📱 PWA — telefonga o'rnatish mumkin

## Texnologiyalar
- HTML, CSS, JavaScript
- Supabase (backend + storage)
- SheetJS (.xls)
- PWA (offline)

## Sozlash
1. Supabase loyihasi yaratish
2. SQL jadvallarni yaratish (README dagi SQL)
3. `config.js` da URL va KEY ni o'zgartirish
4. Brauzerda `asosiy.html` ni ochish

## Fayllar
- `asosiy.*` — bosh sahifa
- `ijarachi.*` — ijarachilar
- `xarajat.*` — xarajatlar
- `hisobot.*` — hisobot
- `navbatchi.*` — navbatchilik
- `config.js` — Supabase + PWA sozlamalari
- `manifest.json`, `sw.js` — PWA
